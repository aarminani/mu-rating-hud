Mu Rating Helper - Third Party Notices
======================================

Mu Rating Helper reads a published rating snapshot and writes one small file
into Tekken 8's SaveGames folder. It distributes no game content, no game
assets, and no mods.

WHAT IT WRITES
--------------
Exactly one file, at:

    %LOCALAPPDATA%\TEKKEN 8\Saved\SaveGames\MuRating.sav

It never deletes a file, never enumerates the folder's contents, and refuses to
overwrite any file of that name it did not write itself. Everything else in that
directory belongs to the game and is left untouched.


WHAT IT SENDS
-------------
Nothing about you. There is no account, no password and no telemetry. The only
outbound request is a download of a static, public ratings snapshot.


WAVU WANK
---------
Rating data is derived from Wavu Wank, a community project. Requests are made in
line with its robots.txt: one request in flight at a time, a minimum ten second
interval, and none of the paths its robots.txt disallows.

To keep that load constant regardless of how many people use this app, the
snapshot is fetched by a single maintainer machine on a slow schedule and
published as a static file. Copies of this app download that file and never
contact Wavu Wank directly.
